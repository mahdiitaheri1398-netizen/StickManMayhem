# StickMan Mayhem – Battle Arena 1.0

نمونه اولیه اندروید، دوبعدی و افقی، تک‌نفره و آفلاین.

## امکانات
- شخصیت قرمز با هدبند و شخصیت آبی با عینک
- هوش مصنوعی ساده برای حریف آبی
- حرکت، پرش، حمله نزدیک و شلیک
- نوار سلامتی، پرتابه‌ها، سکوها و صفحه پایان مسابقه
- کنترل لمسی چنددکمه‌ای و حالت تمام‌صفحه

## ساخت APK با Android Studio
1. ZIP را استخراج کنید.
2. پوشه `StickManMayhem_Android` را در Android Studio با گزینه Open باز کنید.
3. منتظر تکمیل Gradle Sync بمانید.
4. از منوی Build گزینه **Build Bundle(s) / APK(s) > Build APK(s)** را بزنید.
5. فایل خروجی در `app/build/outputs/apk/debug/app-debug.apk` قرار می‌گیرد.

## کنترل‌ها
- ◀ و ▶ حرکت
- ↑ پرش
- ⚔ حمله نزدیک
- ● شلیک
- Ⅱ توقف

این نسخه یک پایه قابل توسعه است؛ هنوز انیمیشن فریم‌به‌فریم، صدا، منوی مراحل، ذخیره رکوردها و طراحی گرافیکی نهایی اضافه نشده‌اند.
